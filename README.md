# 🌱 CLIPFLEX 360° — FNTT Grow

### A planta cresce. Você decide para onde.

O **ClipFlex 360°** é um acessório desenvolvido pela **FNTT Grow** para auxiliar no direcionamento do crescimento vegetal através de treinamento de baixo estresse — LST (*Low Stress Training*).

Projetado para ser simples de utilizar, reutilizável e ajustável, o sistema permite direcionar o caule conforme a necessidade de cada planta.

---

## 🔄 ClipFlex 360°

### Controle de direção em múltiplos ângulos

O sistema permite ajustar a direção do caule de maneira prática, ajudando o cultivador a organizar o espaço disponível e distribuir melhor a planta.

### Principais características

- 🔄 Ajuste multidirecional
- 🌱 Compatível com técnicas de LST
- ♻️ Reutilizável
- 💪 Construção resistente
- 🖨️ Desenvolvido para fabricação por impressão 3D
- 📦 Produto fornecido já montado
- 🇧🇷 Projeto desenvolvido pela FNTT Grow

---

## 🧩 Sobre o projeto

O ClipFlex 360° nasceu como um projeto independente da **FNTT Grow**, combinando:

**design funcional + impressão 3D + experimentação prática.**

O objetivo é desenvolver acessórios simples, reutilizáveis e acessíveis para quem gosta de construir e aprimorar seu próprio sistema de cultivo.
